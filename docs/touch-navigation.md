# Touch Navigation

This page covers how to get around CrossInk with your fingers on touchscreen
devices (including Sticky, X4 Pro, and EEGO). For turning pages and other
gestures while reading,
see [Controls](./controls.md) and
[Touch Reader Controls](./user-guide.md#touch-reader-controls).

Tap anything on screen to select or open it. In long lists, swipe up or down to
move through the list.

## Restoring touch on EEGO

If you turn off the EEGO touchscreen, restarting the device re-enables it
automatically. Up + Down is reserved for EEGO's hardware reset, so it is not
available as a shortcut or Quick Actions trigger. Other devices keep their
existing touchscreen and Up + Down behavior.

## Home-screen swipes

The **Dashboard** and **Minimal** Home screens have swipe shortcuts. Start the
swipe on the main part of the Home screen. You do not need to start at the edge.

| Gesture         | What it does |
| --------------- | ------------ |
| Swipe **down**  | Opens **Settings** |
| Swipe **right** | Opens **Browse Files** (or **Library**, if **Swap Library/File Browser** is on) |
| Swipe **up**    | Opens the Home menu |
| Swipe **left**  | Shows the next recent book |
| Tap the book cover | Opens the book |

The **Lyra** Home screen has one swipe: swipe **left** to show the next recent
book. Use the on-screen menu for everything else.

On X4 Pro, start a down-swipe for Settings below the very top edge. A down-swipe
from the top edge opens the frontlight panel instead. You can still reach
Settings by tapping the settings icon in that panel.

### Browse Files

Tap a folder to open it and tap a book to start reading. Touch and hold a book
to open its context menu. To go up a folder or back to Home, tap the back arrow
or swipe right starting from the left edge.

### The Home menu

Swipe up on the Dashboard or Minimal Home screen to see shortcuts. Which ones
appear depends on what you have set up:

Open File Transfer to access OPDS Browser.

- **Library** (or **Browse Files** when swapped)
- **OPDS Browser**, if you have added an OPDS server
- **Bookmarks & Clippings**, if you have saved any
- **Reading Stats**, if reading stats tracking is on
- **File Transfer**

Tap an item to open it. Tap outside the panel to close it.

### Switching recent books

If your reading history has at least two books, swipe left on the Lyra,
Dashboard, or Minimal Home screen to switch to the other recent book.

## Cover Grid Home

On supported devices such as Sticky and X4 Pro, choose **Settings > Display > UI
Theme > Cover Grid** for a Home screen with the current book and up to six
additional covers. Tap a cover to open its book. This is a separate Home theme
from Library's **Recently Opened View** grid option.

## Going back

Swipe right from the left edge of the screen, or tap the on-screen back arrow
when one is shown, to go back from most screens.
